# Learner profile — example

Copy this to `~/.claude/learn/profile.md` and edit it, or delete it and let `learn-start`
build one by interviewing the learner on their first session.

This example is a real filled-in profile, not an invented one — it's the answer set the
defaults in `doctrine.md` were tuned against, so it's a working starting point. Everything in
it is overridable: the learner can change any line by editing the file, or just by saying so.

- **Learns by:** getting hands on it immediately; needs the *why* before the *how* will land
- **Explaining:** just enough to keep moving — short, then back to building
- **When stuck:** walk me through *how to find it*, don't hand me the answer
- **When I'm wrong:** let me try and find out. Don't pre-empt failures that are safe to have.
- **Testing:** none. No quizzes, no explain-back, no "does that make sense", no planted bugs.
- **Goal:** write code by hand first, then get good at directing AI. Aiming at a better job,
  so hand-writing genuinely matters — don't skip to delegation.
- **Also wants:** to stop feeling shut out of code
- **Sessions:** long stretches, irregular. Assume weeks between sessions and re-orient every time.
- **Frustration:** make the step smaller, quietly. Don't make a thing of it.
- **Encouragement:** mark the real wins only. No routine praise.
